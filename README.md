# Robotic User Interface

友好的机器人交互界面，无论是哪一个机器人，继承并实现RobotBase基类中相对应的解包或组包，也可提供自定义的UI控件，会一并显示在UI中。

开发
  - C++ 17
  - Qt > 6.9
  - CMake > 3.20

跨平台开发
  - Windows
  - Ubuntu

目标包含多种开发工具:
  - 3D模型（TODO） 
  - 自定义加载用户插件(TODO)  
  - 曲线可视化
  - 数据收发
  - 开发工具。

可以通过不同的通信方式接入数据:
  - UDP
  - TCP（TODO）
  - BlueTooth(TODO)
  - Serial Port
  - CSV File
